# Custom sounds

Drop any of these files here and Korbaj will pick them up on launch:

| File        | Used for                     |
|-------------|------------------------------|
| `whip.mp3`  | Whip crack (also `.wav`/`.ogg`) |
| `pat.mp3`   | Pat-mode chime (also `.wav`/`.ogg`) |

Set `KORBAJ_SOUND_MODE=replace` to play only your file, or leave it at the
default (`mix`) to layer your file on top of the built-in synth.
